# Fırıncı Fikret

8-bit (NES tarzı, 256×240) platform oyunu. Fırıncı Fikret, farelerin çaldığı ekşi mayayı kurtarmak için 4 bölümü geçiyor.

- **1-1 Sabah Sokağı**, **1-2 Fırın Mahzeni**, **1-3 Çatılar**, **1-4 Büyük Fırın** (Fare Kral patronu)
- Çörek: büyüme · Simit: simit fırlatma · Kurabiye: kısa süre ölümsüzlük · Kalp: +1 can
- Telefonda ekrandaki NES tarzı kol; klavyede ← → , Boşluk/Z = zıpla, X/Shift = koş/at, Enter = duraklat, M = müzik

Karakterler, bölümler ve müzikler bu oyun için özgün olarak hazırlandı.
