# Ses Yolu 🎤🚗

Sesinle oynanan araba oyunu.

- **Kalın ses** ("Ooo") → araba yassılaşır, alçak geniş delikten geçer
- **İnce ses** ("İiii") → araba incelir, dar uzun delikten geçer
- **Sessiz** → araba normal boyda, kare delikten geçer

Mikrofon izni ister. Mikrofon yoksa ekrandaki KALIN / İNCE düğmeleriyle de oynanır.
